# 🍽️ QR-Based Digital Menu & Restaurant Ordering System
 A complete web-based restaurant ordering system that allows customers to access a digital menu through a QR code, place food orders, and track order status digitally.
 ## 📌 About the Project
 This project is designed to simplify restaurant ordering by connecting customers and restaurant staff through a digital ordering workflow.
 ## ✨ Key Features
 - 📱 QR-based digital menu
- 🛒 Digital food ordering
- 📦 Order status tracking
 ## 🛠️ Technology Stack
- HTML5
- CSS3
- JavaScript
-  PHP
-  MySQL
 - XAMPP
 ## 👥 User Roles
- Customer
- Kitchen Staff
- Waiter
- Admin
## 🔄 System Workflow
1. Customer scans the QR code.
2. Customer browses the digital menu.
3. Customer selects food items and places an order.
4. Order is sent to the kitchen.
5. Kitchen staff updates the order status.
6. Customer tracks the order status.
7. Customer completes the payment.

## ✨ Benefits
- Faster and easier ordering
- Reduces manual ordering errors
- Real-time order status tracking
- Improves restaurant staff coordination
- Provides a better customer experience

## 📁 Project Structure
The project is organized into separate modules for customer, kitchen, waiter, and admin workflows.

## 🚀 How to Run
1. Install XAMPP.
2. Copy the project folder into `xampp/htdocs/`.
3. Start Apache and MySQL from XAMPP Control Panel.
4. Import the database using `database_migration.sql`.
5. Open the project in a web browser through `localhost`.

## 🗄️ Database
The system uses MySQL to store menu items, customer orders, order details, and order status information.
